하트 쉐이딩 듀오 · 기존 시안 폐기 사유와 레퍼런스 재구성
2026-10-21 / V5는 소유자가 거부한 시안이며 기술 검수 통과가 디자인 승인이라는 뜻이 아니다.

1. 무엇을 잘못 판단했는가

문안 길이를 원인으로 단정했다. V5는 마케팅 문안을 538자에서 217자로 줄였지만 닫힌 용기 사진, 큰 헤드라인, 흰 여백의 관계는 그대로였다. 사용자는 제형과 완성감을 보고 싶었는데 설명을 축약하는 데 집중했다. 사진에 정보가 없으면 글을 덜어도 구매 이유가 생기지 않는다.

첫 화면에서 브라운 제형이 보이지 않았다. 노랑·파랑 패키지는 보이지만 쉐딩이라는 제품 종류와 두 명도의 차이를 사진으로 확인하기 어렵다. 실물을 보여주는 열린 제품 자료가 있는데도 닫힌 제품만 확대해서 사용했다.

'두 가지를 따로 챙길 필요 없이'를 강한 USP로 취급했다. 듀얼 구성은 투쿨포스쿨·삐아에도 있다. TAM의 사실은 하이라이터+쉐딩이 아니라 밝은 쉐딩+진한 쉐딩이다. 이 사실을 사용 부위와 실제 제형에 연결해야지, 듀오 자체를 독보적인 이유처럼 다루면 안 된다.

실제 구매 설득에서 가장 중요한 빈칸은 사용 과정과 얼굴 결과다. 거부된 얼굴 사진을 빼는 것은 필요했지만 그 자리를 설명 문구로 메워서 완성되었다고 판단한 것이 잘못이다. 현재 승인된 비다샤 도포/블렌딩/동일조건 얼굴 결과 원본은 확보되지 않았다. 새 렌더나 타사 사진으로 이 근거를 대신하지 않는다.

기술 검수와 시각 판단을 혼동했다. 이미지가 뜨고, 가로 넘침이 없고, PNG가 맞다는 검사는 전달 오류를 잡는다. 구매 설득력·사진 품질·브랜드 완성도를 증명하지 않는다. V5의 '검수 완료' 표현만으로 소유자에게 전달한 판단은 부적절했다.

2. 실제 비교한 레퍼런스

주 기준: 투쿨포스쿨 아트클래스 바이로댕 듀얼 컨투어 스틱 공식 상세.

동일 상품 올리브영:

보조 비교: 삐아 라스트 윤곽 스틱 공식 상세.
https://www.bbia.co.kr/goods/goods_view.php?goodsNo=1000000134

공식 HTML과 상세 원본 이미지/GIF를 내려받아 시각적으로 확인했다. research/reference-manifest.json에 실제 URL, 크기, 프레임 수를 기록했다. 경쟁사의 고객사진·제품사진·카피는 TAM 등록 이미지에 넣지 않는다.

투쿨포스쿨: 바닥과 그림자가 있는 제품 사진을 첫 화면 대부분에 배치하고 제품명은 아래에 둔다. 다음 화면에서 이름·용도·옵션을 설명한다. 이어 실제 팁과 제형, 피부 발색, 사용 장면을 보여준다. TAM V5의 '큰 문장 → 닫힌 용기 → 작은 제형' 순서와 다르다.

삐아: 얼굴 완성감과 실제 제품 장면, 제품·제형이 함께 있는 색 구성, 전후·도포 시연으로 이어진다. 현재 얼굴 사진을 사용할 수 없는 TAM에 모델 중심 도입을 그대로 복제하면 가장 중요한 자리가 다시 빈다. 그래서 제품 중심으로 시작하는 투쿨포스쿨을 주 기준으로 선택했다.

3. V6에서 실제 맞춘 것과 달라진 것

도입: 투쿨포스쿨 1000×1511 사진 우선 화면의 비율을 840×1270으로 맞춤. 열린 제품을 먼저 보여주고, 제품명과 짧은 정의를 하단에 둠. 기존 실물 제품 PNG 두 개를 Blender의 평면에 배치하고 바닥·조명·그림자를 구성했다. 제품 자체를 새로 모델링하거나 생성하지 않았고, 실제 쉐딩 발색 사진으로 주장하지 않는다. 편집 원본은 heart-shading-reference-studio.blend.

제품/색 구성: 중앙 제목 → 짧은 용도 설명 → 옵션별 제품 → 실제 하트 제형 → 색 이름 순서를 따름. 경쟁사는 3옵션, TAM은 2옵션이므로 열 수를 2개로 조정. 경쟁사의 'NEW', 초보 추천 보장, 하이라이터·볼륨 소구를 옮기지 않음.

두 명도/발색: 경쟁사의 팁 설명+컬러 카드 역할을 밝은/진한 쉐딩 설명과 실제 팔 발색으로 치환. 같은 하트 제형의 좌우를 라이트/딥으로 설명하며 샌드와 포그를 라이트/딥으로 혼동하지 않음. 제형·팔 발색 대비를 임의로 올리지 않음.

사용법: 현재 확인 가능한 제품 회전·캡·소량 도포·손끝/브러시 블렌딩만 안내. 실제 얼굴 결과가 있는 것처럼 보이는 그림이나 생성 사진을 넣지 않음.

이것은 경쟁사 전체 상세의 1:1 복제품이 아니다. 제품 도입의 화면 비율·사진 우선순위와 제품/색상 구성의 배치를 맞춘 재구성 검토본이다. 얼굴 결과/도포 영상 영역의 자료 부족은 여전히 남아 있다.

4. 독립 검토와 채택/기각

consult-claude 스킬로 Claude Code CLI를 읽기 전용 호출했다. --no-session-persistence --output-format text를 사용했고 저장/재개 세션은 만들지 않았다. 이것이 제공자 측 데이터 삭제를 의미하지 않는다.

채택: 닫힌 제품 때문에 제형이 보이지 않는 문제, 흰 여백 속 제품만 떠 있는 연출, 작은 하트 제형, 설명 감소만으로는 설득이 생기지 않는다는 비판.
기각: 측정되지 않은 '명도 차 3~5%' 숫자, 측정되지 않은 이미지 면적 비율, 발색 대비를 보정하라는 제안. 이런 수치는 검증된 사실로 쓰지 않고, 제품 색상은 바꾸지 않는다.
판단: 독립 검토는 참고 의견이며 소유자의 시각 승인이나 실제 구매 성과를 대신하지 않는다.

5. 전달 전 확인할 기준

- 첫 화면에 실제 브라운 스틱 끝과 하나의 연결된 하트 구조가 보이는가.
- 레퍼런스와 같은 표시 폭에서 사진/제목/여백의 관계를 직접 비교했는가.
- 샌드/포그 옵션과 라이트/딥 명도를 섞어 설명하지 않았는가.
- 제품 사진의 원본 해상도보다 실제 제품 영역을 확대하지 않았는가.
- 제품·제형·팔 발색의 색을 새로 만들거나 대비로 과장하지 않았는가.
- 잘림·누락·문자 깨짐을 최종 PNG와 모바일 화면 양쪽에서 봤는가.
- 사용 결과 자료가 부족하다는 사실을 '완성'이라는 말로 덮지 않았는가.

현재 상태: 원본 보존. V5 거부 기록 유지. V6 소유자 시각 검토 미완료. 실제 Cafe24 등록·관리자 저장·실기기 확인은 보류.


6. V6 실제 PNG 독립 시각 검토 후 판정

4장의 최종 PNG와 투쿨포스쿨 원본 2장을 별도 검토했다. 판매용 완료 판정은 하지 않는다. V6도 최종 전달안에서 제외하고 레퍼런스와 비교하는 구조 검토본으로만 보존한다.
채택: 팔 발색의 흐릿함, 사용법 문장에 대응하는 회전/도포 장면 부재, 같은 제품 이미지 반복, 실제 결과 없이는 구매 설득이 끝나지 않는다는 지적.
유보/기각: 사진의 기울기를 제품 조립 오류로 단정하거나, 동일 패키지를 제품 오류로 보는 해석은 채택하지 않는다. 원본 사진과 동일한 실물 구조·옵션이다. 제형 표면 반사를 펄 함유 또는 하이라이터의 증거로 단정하지 않는다. 용량은 기존 공식 정보의 2.1g×2를 유지한다. 그림자 방향의 수치 검증 없는 단정과 쉐딩 근거가 0이라는 표현도 사실로 옮기지 않는다.
판단: 외형을 변경하거나 발색 대비를 올려 해결할 일이 아니다. 현재 부족한 것은 실제 도포/블렌딩/얼굴 결과의 검증 가능한 자료와 선명한 근접 사진이다. 제품 설명 프레임을 참고하는 것과 타사의 설득력을 갖추는 것은 다르다.
이번 공개 대상은 분석·비교 검토 기록이다. Cafe24 파일은 기술적으로 준비된 검토 패키지일 뿐 판매용 승인본이 아니다.
