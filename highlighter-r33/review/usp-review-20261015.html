실제 적용한 구매 흐름

원하는 얼굴의 결과 → 실제 펄 영상 → 3색 중 내 선택 → 제형 → 사용 위치와 양 → 성분 → 컬러 선택
  • 실제 광채 영상을 첫 화면으로 이동하고 정물은 마지막 선택 단계로 이동.
  • 히어로를 광대 위에 톡, 빛나는 입체감으로 변경.
  • 색별 사용 장면·기존 공식 톤 추천을 사진 아래 연결.
  • 사용 부위를 원하는 결과와 함께 설명하고 펄감·초기 사용량 문답 추가.
  • 비건·성분은 하단 보조 정보로 유지. 마무리에 실제 컬러 선택 영역으로 이동하는 버튼 추가.

USP와 근거의 연결

컬러를 가진 펄: 기존 3색 피부 발색과 실제 제형 이미지로 보여줍니다. 문스톤은 밝고 시원한 포인트, 구미 핑크는 핑크 메이크업의 생기, 테디 골드는 베이지·브라운 룩의 따뜻한 빛으로 선택을 돕습니다. 사용 장면은 기획 추천이며 피부 톤의 정답 판정이 아닙니다.

부드러운 스틱: 제형 사진과 기존 실제 사용 영상으로 설명합니다. 손끝 사용은 쉬운 방법을 알려주는 역할이며 독점적 장점으로 올리지 않습니다.

비건·성분: 기존 확인된 문안을 하단에 유지합니다. 새 인증 배지, 지속력·모공·밀림 없음, 통제된 전후 비교나 만족도 수치를 만들지 않았습니다.

확인한 것과 남은 판단
