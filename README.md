# tam BEAUTY 공식몰 가안 백업

최신 운영형 v2를 `storefront-v2/`에 저장했습니다. 이 브랜치는 백업용이며 GitHub Pages의 main 배포는 변경하지 않습니다.

## 확인
- [홈](storefront-v2/preview/index.html)
- [상품 목록](storefront-v2/preview/shop.html)
- [모델 룩북](storefront-v2/preview/lookbook.html)
- [카페24 적용 안내](storefront-v2/카페24_적용안내.md)
- [카페24 적용 ZIP](storefront-v2/탐뷰티_카페24_적용파일_260914.zip)

저장소를 내려받아 `storefront-v2/preview/index.html`을 브라우저에서 열면 됩니다. 또는 저장소 루트에서 `python -m http.server 8000` 실행 후 `http://localhost:8000/storefront-v2/preview/`에 접속합니다.

## 포함 내용
25개 미리보기 화면, 젤리 6종·클라우드 8종의 1600px 실제 누끼컷, 한세연·모아 촬영 폴더에서 선정한 모델 룩북 6장, 자체 호스팅 서체와 라이선스, 카페24 템플릿·통합 도구·검증 기록을 포함합니다. HTML/CSS/JS 산출물을 직접 수정할 수 있습니다.

상품 상세의 기존 긴 설명 이미지는 공개 공식몰 원본 URL을 참조하도록 바꿨습니다. 이 영역은 인터넷 연결이 필요합니다. 홈·목록·룩북·제품 대표 이미지는 저장소에 포함돼 있습니다.

장바구니·주문서는 미리보기이며 실제 주문·결제·쿠폰 발급을 수행하지 않습니다. 카페24 실제 스킨 반영과 관리자 환경 검수는 아직 진행하지 않았습니다. 회원·주문 데이터, 로그인 정보와 NAS 촬영 원본은 포함하지 않았습니다.
