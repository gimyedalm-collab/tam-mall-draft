홈페이지 모델을 출발점으로

홈페이지 메인 필름 포스터와 같은 영상 제작에 사용된 정면 레퍼런스를 Higgsfield에 함께 넣었습니다. 눈매, 코와 입술의 비율, 검은 머리와 골드 후프를 기준으로 유지하고, 피부 결·미세한 비대칭·잔머리를 지시했습니다. 참고 기반 생성이므로 원본 얼굴과 완전히 동일하다는 뜻은 아닙니다.

턱 옆에 제품만 드는 포즈를 도포 동작으로 바꿨습니다. 사진에서는 얼굴·손·팁·열린 병이 함께 보이고, 텍스트는 얼굴이나 제품을 덮지 않습니다.

ROUND 03 / 실제 화면 비교

첫 화면과
모바일 리듬 재점검

완성 화면을 힌스·딘토·라네즈 자료와 다시 대조했습니다. 첫 화면 문구의 구체성, 큰 팁과 인물의 크기 대비, 컬러 영역의 길이, 제형 모티프의 전달력을 점검했습니다.

첫 화면 실제 팁, 유리 모티프 교체, 실제 제형 확대와 사용법 색면을 반영했습니다.

힌스 미러 듀 글로스와 딘토 미러리스 립 글로스는 인접 카테고리의 비주얼 레퍼런스입니다. 디올·클라랑스는 직접적인 립오일 메시지 참고입니다. 올리브영 직접 페이지는 접근이 제한되어, 브랜드 공식 자료와 앞서 확보한 공식 상세 이미지로 비교했습니다. 시장 전체 순위나 매출 우열을 판단한 분석은 아닙니다.

브랜드 / 제품관찰한 강점탐에 적용한 방식
힌스 / 미러 듀 글로스완드·인물 크기 대비, 기능별 이미지도포 인물 뒤에 팁 확대, 실제 팁 사진 병기
딘토 / 미러리스 립 글로스모델·소품·컬러의 일관된 캠페인홈페이지 모델, 페일 로즈 톤과 투명감 통일
라네즈 / 글레이즈 크레이즈이름과 연결되는 광택·제형의 시각화젤리광을 보여주는 소재 연출, 실제 제형 별도
클라랑스 / 립 컴포트 오일편안한 사용감과 바르는 방식 설명팁의 면/끝 사용법, 단독/덧바르기 안내
디올 / 립 글로우 오일케어와 윤기를 함께 제시촉촉함을 앞세우고 성분 함유 사실만 짧게

Claude 교차검토와 반영

구성 단계와 화면 제작 후 두 번 독립 자문을 요청했습니다. 비대화식 실행에 --no-session-persistence를 적용해 로컬 Claude Code 세션 이력이 남지 않도록 했습니다. 이 옵션이 제공자의 서버 측 데이터까지 삭제한다는 뜻은 아닙니다.

  • 반영: 동일한 제목·설명·사진 패턴을 줄이고, 도포 인물 → 팁 매크로 → 광택 → 실제 컬러로 역할을 분리.
  • 반영: 첫 화면에 실제로 바르는 행동, 실제 팁 사진, 간결한 세 컬러 비교.
  • 수정·배제: 기존 발색이 AI라는 추측은 오류이므로 바로잡음. 공식 실제 발색을 유지.
  • 수정·배제: 쿨링의 독점성, 1회 완성, AI 단독/덧바르기 전후 증명은 채택하지 않음.

2차 검토 후 실제 수정: 첫 화면으로 공식 팁 사진을 이동하고 헤드라인을 ‘넓게 쓸어 바르는 촉촉한 젤리광’으로 바꿨습니다. 딱딱한 유리 모티프는 제외하고 오일을 펴 바른 광택 연출로 재제작했습니다. 실제 제형 사진은 더 키웠으며, 팁 챕터의 중복 설명을 줄이고 사용법에 로즈 색면을 넣어 흐름을 나눴습니다.

모델 재생성 중에는 원본에 없던 주근깨와 바뀐 완드가 나타난 컷도 있어 제외했습니다. 원본 얼굴의 비율과 제품을 유지하는 국소 보정 방향으로 다시 검토했습니다. AI 팁 확대는 실제 구조를 참고한 캠페인으로만 사용하고, 형상 확인의 기준은 첫 화면의 공식 실제 팁 사진입니다.

쿨링 성분의 기전 설명을 추가하라는 제안은 채택하지 않았습니다. 이번 성분 설명은 확인한 두 오일의 함유 사실에 한정했습니다. 아래 2차 원문은 수정 전 화면을 검토한 결과이며, 수정본에 대한 Claude 승인으로 해석하지 않습니다.

결론부터: V3는 사진 몇 장을 바꿀 문제가 아니라 챕터 구조와 이미지 역할을 다시 짜야 하는 문제입니다.

열람 범위: V3 스크린샷과 힌스·딘토·라네즈 콘택트시트 네 장은 모두 확인했습니다. 홈페이지 필름 모델 원본, 공식 발색 자료, V2 시안은 받지 못했고, 390px 프리뷰의 작은 본문은 일부만 읽혔습니다. 얼굴 동일성과 발색 자료 해상도는 판단에서 제외합니다.

## V3 진단과 제안 반론

- 히어로가 포즈이지 행동이 아닙니다. 병을 볼 옆에 들었을 뿐 넓은 팁이 화면에 없고, "한 겹 더, 탱글하게"는 어느 글로스에나 붙는 문장입니다. 캡션의 "탱글해지는 플럼핑"은 결과 주장이라 수정 대상입니다.
- 빅팁 섹션의 완드는 병과 분리된 3D 렌더에 오일 한 방울을 떨어뜨린 그림입니다. 딘토와 힌스가 똑같이 쓰는 연출이고, 크기 기준이 없어 "넓다"가 눈으로 확인되지 않습니다.
- 전 섹션이 소제목, 헤드라인, 두 줄 본문, 사진 또는 01/02 리스트 순서로 같은 박자입니다. 가장 차별적인 쿨 터치 섹션만 이미지 없는 텍스트 띠입니다. 거꾸로 됐습니다.
- 스케일 대비가 없습니다. 힌스는 거대 완드 옆 작은 모델, 딘토는 사과 대 병, 라네즈는 텍스처 매크로 대 튜브 트리오로 리듬을 만듭니다. V3는 끝까지 중간 샷입니다.
- 쉐이드 섹션이 같은 각도 입술 렌더 세 장으로 페이지 4분의 1을 차지하고, 세 병 사진이 중간과 끝에 두 번 그대로 나옵니다. "젤리 컬렉션"이라는 이름이 비주얼로 번역된 곳이 없습니다.

제안 7섹션의 2·3·4·6번은 모두 보습과 광택을 다시 말하고, 완드는 1·3번에, 세 병은 2·7번에 중복됩니다. 보습은 립오일 카테고리의 기본값이라 헤드라인에서 내려야 합니다. TAM이 소유할 수 있는 조합은 "넓은 팁으로 쓸어 바른다, 닿는 순간 시원하다, 젤리 같은 오일광"입니다. 셋 다 확인된 사실이고, 디올·클라랑스는 팁은 말해도 쿨 터치와 젤리광을 한 세트로 묶지 않습니다. "콕콕 찍지 않고 쓸어 바르는 립오일"은 행위 서술이라 성능 주장 없이 차별화됩니다.

## 최종 아키텍처

860px, Pretendard, 페일 로즈와 화이트 유지. 블록 여섯 개, 블록마다 지배 이미지 하나, 본문 두 줄, 캡션 한 줄이 상한입니다.

- 00 히어로 860×1080. 필름 모델이 넓은 완드를 아랫입술 중앙에 대고 쓸어 바르는 순간, 손과 병이 함께 보입니다. 배경은 단색이 아니라 찬 흰빛이 도는 로즈 그라데이션. 헤드라인 "넓게 쓸어 바르는 립오일." 본문 "넓고 둥근 팁이 입술을 감싸듯 펴 바르고, 닿는 순간 시원하게 젤리 같은 윤기를 남깁니다." 하단에 01 넓은 팁 / 02 쿨 터치 / 03 젤리 글로우 인덱스 띠. 이 띠가 제안 2번을 대체합니다.
- 01 팁 챕터 860×900. 뚜껑 연 실제 병을 좌하단에 작게, 완드는 대각선으로 프레임 밖까지 크게. 헤드라인 "콕콕 찍지 않습니다. 쓸어 바릅니다." 본문 "넓은 면이 입술 폭을 따라 펴지고, 둥근 끝이 입술선 안쪽을 정리합니다." 우하단 160px에 공식 완드 사진 인셋, "실제 어플리케이터" 라벨. 비교 숫자 없음.
- 02 쿨 젤리 글로우 860×860, 좌우 430 분할. 왼쪽은 차갑게 맺힌 투명 젤리 위로 오일이 흐르는 캠페인 렌더, 오른쪽은 같은 모델 입술 클로즈업에 찬 사이드 라이트. 헤드라인 "닿는 순간 시원하고, 젤리처럼 탱글해 보입니다." 본문 "쿨한 사용감과 오일의 윤기가 입술을 촉촉하고 도톰해 보이게 연출합니다." 캡션 "해바라기씨오일·녹차씨오일 함유" 11px. 성분 이야기는 여기서 끝.
- 03 쉐이드 860×760, 3열 260. 열마다 병, 공식 발색 칩 140px에 "실제 발색" 라벨, 이름, 한 줄 무드. 헤드라인 "같은 윤기, 세 가지 온도." 입술 렌더는 중앙 상단 한 장만.

- 05 클로즈 860×620. 세 병 트리오가 처음으로 정면 등장, 품명, 4.3 ml, 세 컬러명, 정보 토글. 중간의 세 병 사진은 모두 제거.

## 핵심 수정 5와 근거 공백

1. 히어로를 포즈에서 행동으로. Higgsfield 프롬프트에 필름 모델 레퍼런스 이미지, 4분의 3 앵글, 85mm, 피부 결 유지, 실제 TAM 병과 넓은 플로킹 팁이 아랫입술에 닿는 순간을 명시. 네거티브에 아이돌풍 범용 얼굴, 과한 속눈썹, 유리알 피부. 크로스리뷰 체크 항목은 팁 형태, 병 비율, 손가락 수, 입술 투명도, 필름 스틸과의 동일성.
2. 캠페인 장치를 "찬 투명 젤리와 오일 흐름" 하나로 통일하고 02 챕터와 쉐이드 배경에 반복. 라네즈 도넛처럼 성분이 아닌 이름 모티프이며, 모든 렌더에 "캠페인 연출 이미지" 라벨.
3. 스케일 리듬 고정. 거대 완드, 작은 병, 매크로 텍스처, 모델 중간 샷을 교대로 두고 중간 샷이 연속되지 않게.
4. 입술 렌더 세 장을 공식 발색 칩으로 교체. 저해상도는 AI 업스케일하지 말고 작게 쓰는 편이 신뢰를 삽니다.
5. 텍스트 전용 띠 전면 삭제. 사용 단계, 포뮬러 노트, 쿨 터치 띠 모두 챕터 캡션으로 흡수.
