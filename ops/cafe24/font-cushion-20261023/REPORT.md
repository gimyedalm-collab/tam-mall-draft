# 공식몰 이미지 최적화·폰트·쿠션 적용 — 2026-10-23

공식몰 `https://tambeauty.kr/`의 대표 디자인을 **skin24/editor30**으로 전환했다.
관리자 대표 표시와 새로 연 공개 홈페이지의 수정 마커를 모두 확인했다.
이전 skin21은 유지했고, 추가 서버 백업은 **skin25 / TAM_폰트쿠션적용전_20261023_skin21**이다.
영문 shop5 대표 skin8은 그대로다. 이번 사용자의 적용 요청이 이전 준비 전용 범위를 대체한다.

## 반영 내용

- 메인·룩북의 반응형 이미지 16개와 두 최적화 템플릿을 실제 대표 스킨으로 적용했다.
- 공통 CSS의 글꼴 이름을 실제 등록된 `Pretendard Variable`로 맞췄다. 기존 `Tam`도 Pretendard 파일의 별칭이지만, 추가 메뉴가 사용한 `Pretendard`는 등록명과 맞지 않아 대체 글꼴이 사용됐다.
- 메인의 중복 전체 가변 폰트 preload를 제거했다. Cafe24 네이티브 분할 폰트는 유지한다.
- 상품23의 오래된 3이미지 상세를 현재 확정된 vegan-261002 / ux-261013 구성인 **정지 이미지10개·영상3개**로 교체하고 관리자 저장까지 완료했다.
- 상세는 최대860px 중앙 배치, 이미지 원래 비율, 첫 이미지 이후 지연 로딩이다. 영상은 기존 GitHub Pages MP4를 네이티브 controls·playsinline·preload=none으로 연결했다. 커스텀 상세 JavaScript는 필요 없다.
- Cafe24 JPG 재압축으로 추가 손실이 생기는 것을 피하려고 기존 JPG의 디코딩 픽셀을 PNG로 보존했다. 업로드한 정지 이미지와 포스터13개 모두 픽셀·ICC 일치 확인. 총 약10.15MB이며, 전체가 첫 화면에 선다운로드되는 구성은 아니다. 원본 마스터는 보존했다.
- 저장 전 상세설명 외 상품 설정548개가 동일함을 비교했다. 상품번호·가격·6옵션·모바일 공통 상세 설정은 유지했다.
