# 최신 상세 통합·Safari·Cafe24 적용 전 검사 — 2026-10-21

GitHub 메인과 공개 미리보기에는 최신 상세 7종이 연결돼 있다. 사용자가 이전 제외 지시를 철회한 쉐이딩듀오도 다른 세션의 최신 V9를 반영했다. Cafe24 운영몰 적용은 완료되지 않았다.

## 반영 및 검증

- 쉐이딩 V9, 클라우드 블러 V13, 파우더 밤 V5, 립 오일 V9, 립 라이너 R34, 밀키 치크 V12, 하이라이터 R33. 메인 영상 V16 유지.
- 이미지 84개 원본 해시·순서, ZIP CRC·내부 이미지 해시, JPG/PNG/GIF 형식, 파일당 10MB 제한, 등록용 HTML 경로 검사 통과. 상품 상세 외 기존 구매·후기 마크업 보존 검사 통과.
- 관리자에서 확인한 실제 무료배송 기준은 **할인 적용 후 30,000원**. 쿠폰 사용 후에도 무조건 무료배송이 유지된다는 잘못된 미리보기 문구와 계산을 수정했다. 운영 설정은 변경하지 않았다. 정책 테스트 4그룹 통과.
- Safari에서 기본 색상 선택 상자가 24px 높이로 표시되는 문제를 발견해 모바일 구간 48px로 수정했다.
- 실제 macOS Safari 26.6.2에서 25개 경로 × 390/1440px = 50개 검사 통과. 가로 넘침 없음, 모바일 입력 16px 이상·높이 48px 이상. 옵션 선택 → 수량 2 → 장바구니 36,000원, 후기 다음 페이지, 모바일 메뉴 동작 통과.
- 최종 화면 소스 `a90fcb0`, [Safari 실행 39581068839](https://github.com/gimyedalm-collab/tam-mall-draft/actions/runs/39581068839) 성공. 초기 실패는 선택 상자를 열기 전 옵션 클릭 및 로딩 완료 전 측정 문제도 포함했으며 최종 실행에서 해결됐다.
- [Pages 실행 39581066965](https://github.com/gimyedalm-collab/tam-mall-draft/actions/runs/39581066965) 성공. 공개 HTML 25개·공통 자원 3개·이미지 84개, 총 112개가 로컬 최종본과 일치했다.

## 저속 회선 조건

로컬 서버의 전체 다운로드를 200,000bytes/s(1.6Mbps)로 제한하고 요청당 150ms 대기를 적용했다. 이는 실물 휴대폰이나 실제 이동통신 RTT 측정이 아니다. 응답은 캐시하지 않았다.

쉐이딩과 파우더 밤의 옵션·수량·장바구니, 메인 메뉴·영상 재생을 확인했다. UI 조작 중 큰 이미지가 계속 내려오는 상황에서도 장바구니 동작이 가능했다. 최종 파우더 검사는 실제 측정 너비 1920px였다. 현재 Chrome 연결의 화면 크기 설정이 적용되지 않은 검사를 모바일 통과로 계산하지 않았다. 앞서 기록한 쉐이딩·메인 모바일 측정과 Safari의 실제 390px 결과는 별도 근거다.

공유 대역폭 조건에서 쉐이딩 첫 이미지 39.0초, 파우더 밤 첫 GIF 38.9초, 메인 영상 56.7초가 관측됐다. 폰트는 최대 50.7초였다. 이 결과는 “빠른 로딩” 또는 Core Web Vitals 개선을 증명하지 않는다. 원본 발색·질감을 손상시키는 재압축은 하지 않았다. 기록된 404는 favicon 1건이며 상품 자원 실패는 없었다.

## Cafe24 확인 결과와 현재 제한

- 로그인된 관리자에서 배송 정책, 채널 쿠폰 3,000원·발급 후 365일·주문서당 1장·최소 금액 제한 없음·별도 특가/협업 상품 2종 제외를 확인했다. 신규 가입 3,000원 쿠폰은 발급 중지 상태다. 쿠폰 사용·실제 주문·결제는 실행하지 않았다.
- 현재 PC 운영 스킨은 skin18, 테스트 스킨은 skin21이다. PC 원본 서버 백업을 18:15:49, 한국어 모바일 원본 백업을 19:03:09에 생성하고 복구 목록에서 확인했다. 로컬 백업 다운로드는 확인되지 않았다. 파일명은 `admin-policy.json`에 기록했다.
- `/web/upload/tam-rollout-qa-20261021` 검증 폴더를 만들었지만 브라우저 연결 도구의 파일 첨부가 `Not allowed`로 거부됐다. 이미지 업로드·Cafe24 주소 표시 검증은 완료하지 못했다. 빈 검증 폴더가 남아 있다.
- 테스트 스킨에는 아직 기존 디자인이 남아 있다. GitHub 미리보기 장바구니/후기를 Cafe24 연동 완료로 취급하지 않는다. 새 디자인의 네이티브 상품·옵션·재고·장바구니·쿠폰·배송·Snap 후기·결제 연결 검증이 남아 있다.
- 실물 iPhone/Android나 인증된 원격 기기 세션은 없어 실물 기기 검사는 미완료다. macOS Safari 성공을 iOS Safari 성공으로 표기하지 않았다.

운영 스킨 전환·상품 상세 저장·상업 정책 변경은 하지 않았다. 즉시 운영몰 전환 가능 판정은 아직 내릴 수 없다. 업로드 연결이 정상화되면 원본 확보 → 격리 후보 스킨 적용 → 네이티브 구매/후기 검증을 이어가야 한다. 로그인은 이미 완료됐으므로 불필요하게 재로그인을 요청하지 않는다.
