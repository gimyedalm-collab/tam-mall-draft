# 쿠폰·혜택·배송 점검 — 2026-10-26

공개 안내에서 두 가지 불일치를 재확인했다. **관리자 설정의 현재값과 회원 쿠폰 실사용 검증은 미완료**다.
이번 작업에서는 쿠폰 생성·발급·사용, 주문 제출, 결제, 고객 알림, 상업 정책 변경을 하지 않았다.

## 현재 공개 화면에서 확인한 문제

1. [회원 혜택 공지299](https://tambeauty.kr/article/notice/1/299/)의 이미지에는 카카오 플친 추가 쿠폰이 **2,000원**으로 표시된다. [립오일 상품](https://tambeauty.kr/product/detail.html?product_no=25)의 안내는 **3,000원**이다. 동일 혜택의 금액 안내가 다르다. 기존 문제 TAM-C24-005가 아직 실서버에 남아 있다.
2. [이용안내](https://tambeauty.kr/shopinfo/guide.html)는 배송안내 영역에 **2일~14일**, 교환/반품안내 영역에 **1일~7일**을 표시한다. 기존 문제 TAM-C24-003이 아직 남아 있다.

공지 이미지에는 신규가입2,000원 적립금, 구매5% 적립, 생일20% 쿠폰, 텍스트 리뷰500원·포토 리뷰1,000원 적립도 표시된다.
이 안내들이 현재 설정과 일치하는지는 관리자 접근 복구 후 확인해야 한다.
신규가입 **쿠폰**의 발급 중지 기록만으로 신규가입 **적립금**도 중지됐다고 판단하지 않는다.
이용안내에는15시 출고 문구도 남아 있으므로 기존14시 운영 기준과 재대조가 필요하다. 임의로 출고 약속을 변경하지 않았다.

## 확인한 정상 동작

- 상품 화면의 카카오 채널 링크가 정상 HTTPS 채널 주소로 연결된다(HTTP200). 채널 방문은 친구 추가나 쿠폰 발급 완료를 뜻하지 않는다.
- 립오일·파우더밤의320/390/1440px 총6개 화면에서3,000원 안내·채널 목적지·기본 옵션·가로 넘침 검사를 통과했다. 비회원 쿠폰함의 표시만으로 회원 보유 쿠폰이나 사용 가능 여부를 판단하지 않았다.
- 실제 공식몰의 격리된 비회원 주문서에서 립오일1개는 상품17,000원 + 배송3,000원 =20,000원,2개는 상품34,000원 + 배송0원 =34,000원으로 표시됐다.
- 위 주문서 검사는 개인정보를 입력하거나 주문을 제출하지 않았다. 쿠폰을 적용한 회원 주문서는 아니다.
- 기존 배송 계산 코드의4개 테스트 그룹을 통과했다. 할인 후 기준29,999/30,000/30,001원 등 경계값을 포함하지만, 이는 Cafe24 회원 쿠폰 실사용 검증을 대신하지 않는다.

## 남은 검증과 연결 상태

Chrome 실행·확장 활성화·native host 설정은 정상으로 확인됐으나 Browser 제어의 탭 생성/페이지 이동이 반복해서 시간 초과됐다.
공식 복구 절차로 새 Chrome 창을 열고 다시 연결해도 페이지 조작이 실패했다. 사용자에게 Browser 플러그인 재설치/연결을 요청했다.
인증 세션을 파일·쿠키에서 추출하거나 다른 자동화로 우회하지 않았다.

연결 복구 후 수행할 항목:

- 쿠폰·적립금·생일·리뷰 혜택과 현재 안내 비교
- 테스트 회원의 보유 쿠폰, 유효기간·최소금액·제외상품·중복 사용 제한 확인
- 실제 회원 주문서에서 쿠폰 적용·해제 및 배송비 재계산 확인
- 확인된 설정에 맞춘 공지299와 배송 안내 수정본 적용 여부 정리

관리자 원본·쿠폰 인증번호·회원 정보는 저장소에 넣지 않는다. 공개 이미지 원본과 주문서 캡처는 비공개 작업 폴더에만 보관한다.
