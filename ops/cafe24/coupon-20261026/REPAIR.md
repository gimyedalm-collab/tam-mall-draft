# 쿠폰 안내 수정본 — 2026-10-26

사용자가 확인된 문제의 수정을 요청했다. **수정본은 준비했으나 Cafe24 저장은 완료하지 못했다.**
기존 탭에서는 `Debugger unattached`, 새 탭에서는 `Runtime.evaluate` 시간 초과가 발생했다.
할인·배송·회원 혜택 설정, 운영 스킨, 게시글 원문은 변경하지 않았다.

## 준비한 변경

- 공지299의 카카오 채널 쿠폰을 3,000원으로 안내하는 텍스트 HTML.
- 이미지 공지를 대체할 모바일 대응 구성. 새 이미지·외부 폰트·스크립트가 필요하지 않다.
- 할인 적용 후 결제금액 30,000원 이상 무료배송, 미만 기본 배송비 3,000원 및 상품별 배송비 예외 설명.
- 쿠폰 사용으로 무료배송 기준 아래로 내려가면 배송비가 추가될 수 있다는 안내.
- 공유 교환/반품 HTML의 배송 기간만 1–7일에서 2–14일로 맞추고 배송비 설명 보완. 그 밖의 기존 교환/반품 문구 보존.

준비 스크립트: `../prepare_policy_copy.py`.
HTML, 원본 백업, 미리보기, 캡처는 Git 밖 `tam-cafe24-output/coupon-20261026/ready`에 보관한다.
원본 백업은 10월23일 기록이므로 실제 저장 직전에 현재 원문을 다시 백업해야 한다.

수정 공지의 로컬 Chromium 320/1440px 검사에서 가로 넘침 없이 쿠폰 금액·유효기간과 두 링크가 표시됨을 확인했다.
320px 전체 캡처를 직접 검토했다. 결과: `policy-copy-qa.json`. 이는 실제 Cafe24 저장/회원 쿠폰 적용 검증이 아니다.

## 적용 전 확인

쿠폰의 세부 조건과 배송 기준은 10월21일 관리자 기록 및 10월23일 재확인 기록에 근거한다.
이번에는 관리자 현재값을 다시 읽지 못했으므로 수정본을 운영몰에 적용한 것으로 처리하지 않는다.

기존 이미지에 있는 가입/구매 적립금, 생일 및 리뷰 혜택은 준비본에 수록하지 않았다.
이를 혜택 폐지로 해석하지 않는다. 관리자 연결이 복구되면 각 혜택을 확인하고 유효한 항목을
최종 공지에 보존한 뒤 저장한다. 신규가입 쿠폰 발급 중지는 신규가입 적립금 중지의 증거가 아니다.

연결 복구 후에는 현재값 대조 → 원본 백업 → 공지와 공유 안내 저장 → 공개몰 재검증 순서로 진행한다.
회원 쿠폰 실제 적용/해제 검증은 아직 남아 있다. 주문 제출이나 결제는 이번 수정에 포함하지 않는다.
