# 공통 푸터 적용 — 2026-10-26

공식몰 대표 디자인을 **skin27/editor33, TAM_푸터정리_20261026**으로 전환했다.
직전 운영 skin26/editor32를 수정하지 않고 보존했다. 영문 shop5 대표 skin8은 유지했다.
관리자 대표 표시, 캐시 갱신 후 일반 공개 주소와 별도 브라우저에서 실제 반영을 확인했다.

## 변경 내용

- 메인에 별도로 들어 있던 푸터를 제거하고 `moa/layout/footer.html` 한 곳을 사용한다.
- 고객지원·주문·배송 링크를 먼저 배치하고, 사업자 정보·입금 안내·약관을 아래에 정리했다.
- 푸터 내부 카카오 문의 중복을 제거하고, 중복된 이용안내 링크를 배송·교환·반품 안내로 모았다.
- 기존 로고와 배경색을 유지했다. 글꼴·간격을 통일하고 모바일 링크에 최소44px 높이를 적용했다.
- 사업자정보 확인 링크가 한 글자씩 끊기지 않게 했다. 사업자 정보는 접지 않고 계속 표시한다.
- 상품 상세의 기존 전역 `p` 스타일이 푸터 운영시간·계좌·저작권 문구를 맑은 고딕/검정으로 덮어쓰던 문제를 푸터 범위 안에서 수정했다.
- 전화번호·운영시간은 Cafe24 변수, 사업자 정보는 기존 company_info import를 계속 사용한다. 사업자정보 확인 핸들러도 그대로다.
- 공통 footer 파일의 결제 진행 표시·멀티숍·앱 import와, 기존 head 내용 및 메인 푸터 밖 내용은 원문 비교로 보존했다.
- GitHub 미리보기25페이지에도 같은 구성을 적용했다. 페이지 본문은 그대로이며 공통 CSS 링크만 추가했다.
