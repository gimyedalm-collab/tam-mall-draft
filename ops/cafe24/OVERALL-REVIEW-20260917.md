# 가안 전체 재검수

범위: 확정 메인, SHOP, ABOUT, LOOKBOOK, 두 라인, 쿠션·틴트 상세, 검색, 장바구니, 로그인. PC 1440px / 모바일 390·320px. 실제 운영몰·관리자·주문 데이터는 변경하지 않았다.

## 확인과 수정
- 주요 11개 화면 × 3개 폭에서 가로 넘침, 로드 완료 이미지 오류, 문자 대체 기호, JavaScript 예외 없음. 메인/소개/상품 목록은 아래까지 스크롤해 지연 로딩 후 캡처를 확인했다.
- 로고가 이전 메인으로 돌아가던 오류를 재현했다. `index.html`을 확정 `design-only.html`로 연결하고, 기본 경로로 공유해도 같은 시안이 열리도록 수정했다.
- 메인 메뉴에 장바구니 링크를 추가했다.
- 쿠션 최종 상세 10개 이미지의 원본 해시·순서·크기·이음새와 옵션 복귀 버튼을 검증했다.
- 쿠션 상세 하단에 ‘색상 선택으로 돌아가기’를 추가했다. 실제 구매 기능을 가장하는 버튼이 아니다.
- 일반 페이지 모바일 메뉴도 바깥 터치로 닫히도록 보완했다. 열린 모바일 메뉴 중에는 자동 카카오 팝업이 뜨지 않도록 차단했다.
- 미리보기 장바구니 담기/수량 변경/삭제, 팝업 열기/닫기/Escape/24시간 숨김, 무료배송 표시를 브라우저에서 확인했다.
- Claude CLI 독립 코드 검수도 홈 연결, 장바구니 진입, 긴 상세 복귀, 모바일 메뉴/팝업 충돌을 지적했다. Claude는 브라우저 시각 검수는 하지 않았으며, 직접 브라우저로 확인한 결과와 구분한다.

## 남은 판단 및 실제 운영 전 작업
- 메인은 흰 배경과 제품 색 중심으로 유지된다. ABOUT은 라인명 중심 문구 및 전체 제품 목록이 남아 SHOP과 역할이 겹친다. 오류는 아니며 확정 디자인을 임의 재설계하지 않았다.
- 최종 상세 원본은 43,778,675 bytes이며, 그중 애니메이션 WebP 3개가 약 38.2MB다. 지연 로딩은 적용됐으나 저속 모바일 체감 성능까지 통과했다고 볼 수 없다. 원본은 보존하고 운영용 파생본의 화질/용량 비교 및 Cafe24 업로드 확인이 남았다.
- 제품 상단 누끼컷과 상세 속 제품 렌더의 광택 차이는 원본 자료 간 차이이며 임의 보정하지 않았다.
- 리뷰/문의, 실결제, 회원·쿠폰 발급 및 적용, 관리자 배송 조건, 실제 재고·휴일 기반 당일 출고는 Cafe24 연결 후 검증해야 한다. 현재 가안으로 작동 완료를 주장하지 않는다.

검증 도구: `review_preview.py`, `check_review_fixes.py`, `check_cushion_detail.py`, `check_purchase_preview.py`. 로컬 캡처와 상세 실행 결과는 비공개 `runs/`에 저장한다.
