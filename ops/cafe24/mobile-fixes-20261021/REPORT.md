앞선 모바일 감사에서 확인한 네 가지 결함을 수정했다. 기존 상품 디자인과 미디어 원본은 유지하며 GitHub 메인 스토어프런트에 적용했다.

배포 소스 `678c9b5`, GitHub Pages 실행 `39571970349` 성공. 공개 파일32개가 로컬 수정본과 일치하며, 공개 메인/파우더 밤320px 화면과 후기 다음 페이지 이동도 확인했다.

## 수정 내용

- 파우더 밤: 첫 이미지는 우선 로딩, 나머지 13개는 지연 로딩, 전체 비동기 디코딩. 생성기·납품 HTML 3종·ZIP·메인 상품 상세를 함께 갱신했다. 이미지 파일 자체는 변경하지 않았다.
- 조작 영역: 모바일 헤더·푸터·장바구니 수량·필터·룩북 링크 등 작은 링크와 버튼을 최소 44px로 보완했다. 헤더 로그인 숨김 규칙의 우선순위를 수정했으며 메뉴에서 로그인 접근이 유지된다.
- 입력 글자: 모바일 상품 옵션/수량·로그인·주문서 입력과 선택 글자를 16px로 조정했다.
- 후기 페이지 번호: 480px 이하에서 번호 3개, 넓은 화면에서 5개를 표시한다. 이전/다음 버튼을 유지하며, 화면 너비 변경 시 번호 영역을 갱신한다. 줄바꿈도 허용해 좁은 화면 넘침을 방지한다.

25개 스토어프런트 HTML의 공통 CSS/JS 캐시 버전을 갱신했다. 쉐이딩듀오 상품109는 공통 자원의 캐시 버전만 변경했으며 상세 구성과 미디어는 기존 상태다. 다른 작업에서 이미 main에 올라온 독립형 Heart Shading V9 커밋은 보존했다.

## 검증

- Chrome 뷰포트 320·390·430·768px × 25개 경로 = 100건: 문서 가로 넘침, 화면 밖 조작 요소, 검사 범위 내 44px 미만 조작 영역, 16px 미만 입력 글자 모두 없음. 상품 화면 초기화 완료 후 측정했다.
- PC 1440×900 및 가로 화면 844×390에서 주요 6개 경로 = 12건: 문서 가로 넘침과 첫 화면 이미지 로드 실패 없음. PC의 기존 작은 글자/링크는 모바일 기준으로 판정하지 않았다.
- 파우더 밤 첫 진입 시 상세 14개 중 4개만 로드되고 10개는 미로드 상태였다. 스크롤로 후기 영역에 이동한 뒤14개 모두 로드됨을 확인했다. 브라우저가 가까운 이미지를 미리 받는 동작은 정상이다.
- 후기 다음 페이지 1→2, 이전 페이지 2→1 및 첫 페이지 이전 버튼 비활성, 모바일 5개/PC 7개 전체 버튼 확인.

- 여섯 상세의 미디어 78개 해시/순서 및 상세 외 구매 UI 보존 검사 통과. 파우더 생성기 출력 속성, 납품 HTML 3종, ZIP CRC와 내용 일치 검사 통과.
