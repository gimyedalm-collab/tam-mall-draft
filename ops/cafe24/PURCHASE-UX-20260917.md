# 구매 화면·카카오 채널·출고 안내

사용자 요청: 쿠폰 때문에 무료배송이 취소되지 않게 유지하고, 구매 화면을 정리한다.
카카오 채널 추가 팝업과 오후 2시 이전 당일 출고 안내를 준비한다.

후속 확정: 쿠폰·무료배송·할인 조건은 실제 관리자 설정을 그대로 유지한다.
먼저 읽어 UI에 반영하며, 이전의 ‘쿠폰 사용 후에도 무료배송 유지’ 요구와 실제 설정이
다르면 그 차이를 알리고 운영 조건을 임의 변경하지 않는다.
출고 기준은 평일 오후 2시 이전 결제 완료, 주말·공휴일 제외로 사용자가 확인했다.

## 반영한 가안

- 14개 상품 상세: 할인율을 검정으로 정리, 구매 링크를 주 버튼으로, 장바구니를 보조 버튼으로 배치.
- 배송 안내: 상품 할인 적용 후·쿠폰 사용 전 상품 합계 30,000원 기준. 쿠폰 차감으로
  무료배송 자격을 취소하지 않는다. 현재 상품 선택 기준의 안내이며 실제 장바구니 전체 계산은 아니다.
- 카카오 채널: 사용자가 혜택을 즉시 알 수 있도록 현재 공식몰 상품 상세에 표시된
  3,000원을 가안 기준으로 버튼과 팝업에 명시한다. 2,000원 안내와의 불일치는 미해결이며,
  운영 연결 시 관리자 확인 후 `couponAmount`와 `couponAmountVerified`를 설정한다. 기존 공식 채널
  `https://pf.kakao.com/_nxhIxhn`로 이동한다. 클릭만으로 친구 추가나 쿠폰 발급 완료라고 처리하지 않는다.
- 후속 디자인 검토: 밑줄 텍스트만 있던 혜택 링크를 얇은 테두리의 가로 버튼으로 변경.
  작은 노란 ‘카카오톡’ 표시, ‘채널 추가 시 / 3,000원 쿠폰’, 이동 화살표로 식별성을 높인다.
  제품 이미지·구매 버튼보다 시각적 비중이 커지지 않게 큰 노란 배경은 사용하지 않는다.
- 팝업: 12초 경과 + 320px 이상 스크롤 + 메인 영상/상품 구매 영역을 지난 뒤 자동 노출.
  폼 입력 중에는 자동 노출하지 않는다. 탭 세션당 한 번, 닫기·Escape·24시간 숨김 제공.
  수동 혜택 링크로 다시 열 수 있다. 자동 노출은 키보드 포커스를 빼앗지 않는다.
  장바구니·주문서·로그인·가입·쿠폰함에서는 자동 유도 기능을 실행하지 않는다.
- 출고: 사용자가 평일 오후 2시 이전 결제 완료 시 당일 출고를 확인했다.
  현재는 미리보기이며 운영몰에는 재고·출고센터 휴무일·공휴일 달력을 연결한 뒤 적용한다.

## 운영몰 연결 시

원본 스킨과 관리자 접근이 없으므로 현재 운영몰 설정·화면은 변경하지 않았다.
재사용 CSS/JS를 `storefront-v2/cafe24/tam/assets`에 동기화했다. 원본 스킨을 확보한 뒤
선택적으로 로드하며, 미리보기 어댑터나 상품 가격 배열은 운영 스킨에 넣지 않는다.

1. Cafe24 배송비 계산은 최신 사용자 지시대로 관리자 현재 설정을 유지한다. 쿠폰/적립금 차감 기준과
   상품별 예외를 확인하고, 29,999/30,000/30,001원 주문에 쿠폰 적용 전후 배송비를 검증한다.
   화면 JS의 `shipping()`은 미리보기 계산일 뿐 서버 배송비를 변경하지 않는다.
2. 구매 버튼·옵션·재고·간편결제 SDK는 기존 핸들러와 브랜드 규격을 보존한다.
   새 스타일로 기존 위젯·고객지원 팝업을 무작정 가리지 않는다. 기존 유도 팝업이 있으면
   먼저 목록화하여 중복 노출을 제거한다.
3. 전용 모듈에 `window.TAM_PURCHASE_CONFIG`를 명시해야 운영 스킨에서 동작한다.
   팝업 설정은 `popupEnabled`, `channelUrl`, `popupDelay`를 사용한다.
   수동 링크 위치는 `[data-tam-channel-trigger-host]`로 지정한다.
4. `[data-tam-dispatch]`와 `dispatch` 설정은 실제 출고 정책 확인 후 연결한다.
   `enabled`, `eligible`, `calendar: {verified, from, to, closedDates}`가 필요하다.
   재고·예약 여부에 따라 `eligible`을 갱신하고, 출고센터 휴무일·공휴일을 검증한 달력을 공급한다.
   달력 미확인·기간 만료·대상 아님이면 ‘오늘 출고’를 약속하지 않는다.
   KST 14:00 정각부터 다음 영업일로 전환하며 금요일·주말·휴무일을 건너뛴다.
   브라우저 시간은 참고 안내용이며 주문 판정은 서버 결제 시각을 사용한다.
5. 당일 출고는 당일 도착과 다르다. 실제 출고 보장을 광고하기 전에 운영팀 처리 가능 여부와
   제외 상품을 확인한다. 임의로 상품 전체를 당일 출고 대상으로 지정하지 않는다.

  KST 마감, 주말·임시 휴무, 미확인 달력/재고 예외.
