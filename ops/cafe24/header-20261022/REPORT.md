# 홈 투명 헤더 및 후속 검사 — 2026-10-22

사용자 승인에 따라 홈페이지 첫 화면의 흰 헤더 공간을 없애고 영상 위에 내비게이션을 배치했다. 스크롤 16px 이후 또는 모바일 메뉴를 열면 흰 배경으로 전환한다. 상품 페이지의 기존 흰 헤더는 유지한다.

## 구현

- 홈 전용 `home-header.css/js`로 적용 범위를 제한했다. 영상 시작 장면에서는 흰 글자와 상단 그라데이션을 사용하고, 기존 영상 마지막 밝은 장면에서는 검은 글자로 전환한다.
- 기존 V16 영상과 포스터, 상세 이미지의 바이트는 변경하지 않았다. 영상은 16:9 전체 구도를 유지하며 높이를 화면 이내로 제한한다. 넓고 낮은 화면에는 좌우 여백이 생긴다.
- 모바일 재생 버튼은 영상 오른쪽 아래로 이동해 헤더와 겹치지 않게 했다. 모바일 메뉴는 높이가 제한되며 내부 스크롤이 가능하다.
- JS가 준비되면 고정 헤더를 활성화한다. 기존 Escape·바깥 클릭·화면 크기 변경 시 메뉴 닫힘 동작을 유지한다.

## 확인된 결과

- macOS Safari의 기존 25개 경로 × 390/1440px = 50개 레이아웃 검사, 옵션·수량 2·미리보기 장바구니 36,000원, 후기 페이지 넘김, 메뉴 동작 통과.
- Safari 홈 6개 크기에서 영상 상단 0, 16:9 유지, 화면 높이 이내, 가로 넘침 없음, 버튼과 헤더 비중첩, 스크롤 시 흰 고정 헤더, 메뉴 열림과 Escape 닫힘, 영상 끝 검은 글자 전환 통과. 요청 320px은 macOS 창 최소 너비 때문에 실제 336px이었다. 나머지 실제 너비는 390/768/1440/1920/844px이다.
- Windows Chrome 390×844 화면에서 영상과 메뉴 시각 확인, 메뉴 열림 시 흰 배경 및 닫힘 시 투명 복귀 확인. 데스크톱 1920×911에서 영상 높이 910.98px, 상단 0, 가로 넘침 없음.
- 실제 320×844 Chrome 검사에서 콘텐츠 너비 305px, 영상 305×171.56px, 가로 넘침 없음. 메뉴 20–64px, 로고 94–185px, 우측 기능 193–285px로 서로 겹치지 않는다. 펼친 메뉴와 44px 터치 영역도 확인했다.
- 7개 상품 상세·84개 이미지의 해시·순서·상세 외 마크업 보존 검사 통과. 배송 정책 계산 4개 테스트 통과.
- 최종 소스 `655798b`, [Safari 실행 39703829646](https://github.com/gimyedalm-collab/tam-mall-draft/actions/runs/39703829646) 전체 성공. Safari 26.6.2(macOS VM), 일반 50개 + 홈 6개 크기 + 저속 3개 경로 검사 통과.

## 저속 회선 조건 검사

공유 200,000bytes/s(1.6Mbps), 요청당 150ms 대기, 캐시 금지 서버에서 실제 측정 너비 390px을 확인했다. 메인 메뉴 열림 9.02초, 쉐이딩 옵션·수량·장바구니 완료 17.72초, 파우더 밤 완료 8.29초였다. 이는 이동통신 실측·LCP·Core Web Vitals가 아닌 순차 테스트의 UI 준비 및 조작 완료 시간이다. 앞 페이지의 취소 중 요청과 공유 대역폭 영향을 포함한다.

쉐이딩은 조작 완료 시 상세 이미지 0/6개, 파우더 밤은 2/14개가 완전히 로드된 상태였다. 미디어 로딩 중 조작 가능함을 확인했으며 빠른 이미지 로딩을 증명하지 않는다. 기록된 HTTP 응답은 200/206이고 자원 404는 없다. 큰 원본 미디어의 저속 로딩 제한은 남는다.

테스트 서버의 역방향 DNS 초기화 지연을 제거하고 Safari 영상 요청용 단일 바이트 범위를 지원했다. 로컬에서 전체/부분/끝부분/잘못된 범위 200·206·416 응답 및 바이트를 확인했다. Safari 자동화는 `pageLoadStrategy=none`으로 화면 도착과 스타일·구매 UI 준비를 직접 기다려 미디어 전체 로딩 대기와 조작 검사를 분리했다. 이전 실행의 자동화 시간 초과를 사이트 클릭 실패로 오인하지 않았다.

## Cafe24 및 실물 기기

기존 파일 첨부 `-32000 Not allowed` 오류에 대해 브라우저 공식 안내의 Chrome 확장 프로그램 ‘파일 URL에 대한 액세스 허용’ 설정을 사용자에게 요청했다. 권한 변경 완료 답변과 실제 업로드 성공은 아직 확인하지 못했다. 관리자 작업 탭은 `/admin/php/shop1/`에서 화면/대화상자 조회가 반복 시간 초과되어 현재 인증 상태를 판정할 수 없다. 임의로 로그아웃 또는 세션 만료라고 단정하지 않았다.

현재 연결된 iPhone/Android 장치 및 제공된 원격 실물 기기 서비스가 없다. macOS Safari와 화면 너비 검사는 실물 iPhone/iOS Safari 검사와 구분한다. 새 운영 스킨 전환, 상품 상세 저장, 실제 결제는 실행하지 않았다. 후보 스킨21의 네이티브 구매·쿠폰·배송·Snap 리뷰 연결 검증이 남아 있으므로 즉시 운영 적용 완료 판정은 할 수 없다.
