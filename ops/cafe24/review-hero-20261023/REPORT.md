- 메인 파우더밤·립 이미지의 `sizes`가 실제 확대된 그림 크기를 반영하지 못했다. PC에서는 약578/592px에480px 파일을,390px/DPR3에서는 약291/343px에800px 파일을 선택했다. 실제 표시 크기를 반영하고 기존 원본1536px 등을 srcset 후보에 추가했다. 화보에는 이미 검증된1600px 파일 및 원본2800px 후보를 추가했다.
