# 탐뷰티 현재 운영몰 기능 보존 검수 — 2026-09-17

공개 사이트를 실제 Chromium으로 PC(1440×1000), iPhone13 뷰포트에서 확인했습니다. 관리자·회원 로그인, 쿠폰 발급, 장바구니 제출, 주문/결제, 게시물 작성은 실행하지 않았습니다. 화면 존재·일부 UI 동작과 실제 거래 성공을 구분했습니다.

## 결론

현재 기능은 새 디자인에서도 카페24 기본 모듈과 기존 앱 연결을 유지하는 방식으로 구현할 수 있습니다. 다만 관리자 권한/앱 설치 상태/정책을 읽기 전에는 “모든 기능이 이미 이식 가능하다고 검증됐다”고 할 수 없습니다. 특히 리뷰, 간편결제, 소셜로그인, 출고 안내, 광고 추적은 정적 HTML 복사만으로 보존되지 않습니다.

## 실제 확인한 동작과 한계

- [립112](https://tambeauty.kr/product/detail.html?product_no=112): 01 밀크베리 선택 시 14,400원(1개), 무료배송까지15,600원으로 갱신. 정가는16,000원, 할인10%. 옵션 선택은 검증했으나 구매 버튼 제출은 하지 않음.
- [쿠션23](https://tambeauty.kr/product/detail.html?product_no=23): 30,000원, 6색상, 리뷰164 표시, 출고마감 안내. 후속 반복 점검에서 커스텀 색상 선택과 합계 갱신까지 PC/모바일 모두 확인. 전체 옵션별 재고와 실제 구매는 별도 검증 대상.
- Snap 리뷰 iframe 안에 이미지/컨트롤 로드를 확인. 고객 후기 텍스트·회원 식별자는 보고서에 수집하지 않음. 문의에는 board_no=6 작성 경로가 있고 SnapQ 스크립트도 존재하나 둘의 운영 관계는 미확인.
- 쿠폰함·관심상품은 로그인 화면으로 이동. 주문조회에는 비회원조회 입구 존재. 상품 없이 주문서에 직접 접근하면 홈으로 이동하므로 실제 주문서 구성·PG·결제 성공은 아직 미확인.
- PC/모바일 스크린샷으로 메인·상품·로그인 확인. 모든 화면 폭의 전체 기능 회귀검수를 완료했다는 뜻은 아님.

## 관리자 접속 후 먼저 해결할 불일치

1. **혜택 금액:** [회원혜택 공지](https://tambeauty.kr/article/notice/1/299/) 이미지에는 신규2,000적립금·카카오채널2,000쿠폰이 적혀 있으나 헤더 JOIN +3,000·상품 채널3,000원과 다름. 실제 운영값을 읽고 통일할 것. 같은 이미지의 구매5%, 생일20%, 리뷰500/1,000원도 현재 설정 검증 필요.
2. **배송기간:** [이용안내](https://tambeauty.kr/shopinfo/guide.html)에 2~14일과 1~7일이 함께 있음. 실제 출고/배송 안내와 맞출 것.
3. **상품 노출:** SHOP은14개지만 [쿠션 검색](https://tambeauty.kr/product/search.html?keyword=%EC%BF%A0%EC%85%98)에 특수 재구매상품129도 노출. 검색·분류·회원별 구매 제한을 확인하기 전 전체 상품을 무조건 한 목록에 노출하지 말 것.
4. **연동 권한:** Snap/간편결제/소셜로그인/광고태그를 기존 계정으로 유지할 수 있는지, 새 스킨 추가 설치가 필요한지 확인할 것.
