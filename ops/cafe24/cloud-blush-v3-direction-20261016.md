# Cloud blush V3 · 제작 전 결정 기록

2026-10-16. 사용자 요청: 첫 방향을 유지하고, 경우의 수를 정리한 뒤 제작한다. 이 문서는 시각적 선호에 대한 제작 판단이며 구매 전환 검증이나 사용자 승인 기록이 아니다.

## 고정 기준

- 첫 시안의 기준인 Lip Liner / Milky Cheek 상세의 860px, Pretendard·Manrope, 중앙 제목, 얇은 영문 라벨, 블러시·화이트·중성 배경, 2열 발색 비교를 유지한다.
- 주인공은 크림투파우더 사용감과 실제 여섯 컬러다. 모아 사용은 허용 사항이며 반드시 넣어야 하는 조건은 아니다.
- 이미 밝기를 조정해 제시한 9.6초 영상을 그대로 사용한다. 새로운 영상 편집·피부 보정·색 보정은 하지 않는다.
- 여섯 이름과 실제 발색/제형 이미지, 공식 제품 정보는 V1과 동일하게 유지한다.
- 다른 제품, 기존 V1/V2 및 Cafe24 운영 페이지를 변경하지 않는다.

## 선택지와 판단

| 구성 | 이점 | 남는 단점 | 판단 |
|---|---|---|---|
| 제품컷 → 제형 → 컬러 | 첫 시안의 도입 유지, 제형이 컬러 선택보다 먼저 나옴 | 제품컷 선택이 잘못되면 광택 인상과 충돌 | 기본 구성 채택 |
| 영상부터 시작 | 제품 특성을 빨리 보여줌 | 재생 전 첫인상에 의존, 기존 캠페인 도입 약화 | 제외 |
| 모델부터 시작 | 완성 메이크업 분위기를 먼저 보여줌 | 모델이 제품보다 앞서고 V2의 우선순위 문제 반복 | 제외 |
| 제품 구성에서 모아 생략 | 가장 짧고 정보 흐름이 단순 | 발색 자료 외에 전체 메이크업 인상이 없음 | 비교 후보로 확인 |
| 모아 얼굴·제품을 3:2로 크롭 | 제품과 완성 룩을 한 장으로 연결 | 보라 배경의 대비는 남음 | 영상과 같은 폭·높이 이하로 제한해 채택 |

## 문안 역할 확정

| 영역 | 역할 | 문안 |
|---|---|---|
| 도입 | 볼에 표현되는 인상 | 부드럽게 물드는 / 보송한 블러 컬러. |
| 도입 보조 | 범위 안내 | 나의 볼에 더하는 / 여섯 가지 쉐이크 컬러. |
| 제형 | 크림투파우더 이해 | 크림에서 보송함으로. |
| 제형 보조 | 영상 미재생 시에도 전달 | 부드럽게 펴 발리는 크림이 / 볼 위에서는 파우더리하게 마무리돼요. |
| 컬러 | 실제 비교·선택 | 나의 볼에 어울리는 / 여섯 가지 쉐이크 컬러. |
| 사용법 | 양과 덧바르기 | 소량으로 시작해, / 원하는 색감만큼. |
| 성분 | 부차적 포뮬러 정보 | 네 가지 식물성 오일을 담은 / 비건 포뮬러. |
| 마무리 | 선택 환기 | 오늘의 볼에 어울리는 / 컬러를 골라보세요. |

영상 숫자·단계선은 제거한다. 실제 사용법의 세 단계는 행동 순서이므로 유지한다. 성분은 무관한 사진으로 채우지 않고 작은 제목과 짧은 성분명으로 높이를 줄인다. 단순한 단어 출현 횟수 대신 영역마다 전달하는 정보가 다른지 확인한다.

## 독립 검토의 적용 범위

consult-claude를 비대화형 --no-session-persistence --output-format text, 도구 없이 사용해 문안·구성의 논리만 검토했다. 원본 이미지를 보지 않은 텍스트 자문이다.

반영: 핑크 원본의 반사광 리스크, 영상 미재생 시 설명 유지, 도입/마무리의 문안 역할 분리.
그대로 따르지 않은 제안: 비건 표기는 기존 공식 자료로 확인돼 있으므로 임의 삭제하지 않는다. 모아를 색 비교 뒤로 무조건 이동하면 사용자 요청과 다른 흐름 변경이 되므로 실제 크롭 비교를 기준으로 판단한다. 단어 반복 횟수를 일률적인 금지 규칙으로 쓰지 않는다.

## 공개 전 검수 기준

1. 제품컷·영상·모델·컬러표를 한 페이지로 보고 배경색과 시선 흐름을 확인한다.
2. 모아의 얼굴과 블러셔가 프레임 안에 있고, 모델 이미지가 제형 영상보다 크지 않아야 한다.
3. 크림투파우더 설명은 컬러표보다 먼저 읽히며, 영상 미재생 상태에서도 이해할 수 있어야 한다.
4. V2의 숫자 단계선과 같은 설명의 반복을 재도입하지 않는다.
5. 320/390/600/860/1440px에서 넘침, 줄바꿈, 이미지 비율을 확인한다. 무음 재생·수동 정지 유지·화면 밖 정지·동작 줄이기를 확인한다.
6. 12개 색상 비교 자산, 공식 제품 정보, 수정 영상의 해시를 대조한다.
7. 기준 통과는 기술·편집 검수이며, 사용자의 디자인 수용이나 성과 검증을 대신하지 않는다.
